# Wardrobe Buddy (web app)

This repository only hosts the built web app at **https://wardrobe-buddy.github.io/** (GitHub Pages).
The app keeps all data in the visitor's own browser; nothing is sent to this site. It has its own web address so its browser storage is not shared with other sites (decision D-055).

Source code, docs and decisions: https://github.com/cutiermn-commits/Ludo_Mani/tree/ludo-app/wardrobe-buddy
Rebuild: `cd wardrobe-buddy && npm run build:web`, then copy `dist-site/` here.
